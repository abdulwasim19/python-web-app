# 🐍 Python Web App

A simple web application built with **Python and Flask** to learn and practice the fundamentals of Python-based web development.

This project was created as a practical learning project to understand how a Python backend connects with HTML/CSS and handles web requests.

---

This project demonstrates the basic structure of a Python web application using Flask.

It helped me understand concepts such as:

* Python web development
* Flask application structure
* Routing
* HTML templates
* CSS styling
* HTTP requests
* Backend and frontend communication
* Running a web application locally

The main purpose of this project is to build a strong foundation in **Python backend development**.

## ⚙️ How It Works

The application follows a simple request-response flow:

```text
User
  │
  ▼
Web Browser
  │
  │ HTTP Request
  ▼
Flask Application
  │
  │ Python Logic
  ▼
Jinja2 Template
  │
  ▼
HTML + CSS
  │
  ▼
Web Browser
```

Flask receives requests from the browser, processes them using Python, and returns the appropriate HTML page.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:abdulwasim19/python-web-app.git
```

### 2. Enter the project directory

```bash
cd python-web-app
```

### 3. Create a virtual environment

```bash
python3 -m venv venv
```

### 4. Activate the virtual environment

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python3 app.py
```

### 7. Open the application

Open your browser and visit:

```text
http://127.0.0.1:5000
```
